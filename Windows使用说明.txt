三维动作捕捉标记点智能校准软件 — Windows x64

一、在 Windows 电脑生成程序
1. 解压整个源码打包包，不要在 ZIP 内直接运行。
2. 安装 Python 3.11 或 3.12 的 Windows x64 版本。安装来源：
   https://www.python.org/downloads/windows/
3. 双击 build_windows.bat。首次需要联网下载依赖。
4. 脚本运行测试、打包并实际启动生成的 EXE 进行自检。
5. 成功后生成 dist\三维动作捕捉标记点智能校准软件-Windows-x64.zip。

二、交给使用者
把上面的成品 ZIP 发给 Windows 使用者。解压后双击
三维动作捕捉标记点智能校准软件\三维动作捕捉标记点智能校准软件.exe。
使用者无需安装 Python。必须保留同目录的 _internal 文件夹；
不要只发送一个 EXE。这个版本面向 Windows 10/11 x64。

三、保存位置
项目 JSON 和导出的 C3D 仍保存到你选择的位置。
打包版的布局、建模方案、自动恢复副本及启动日志位于：
%LOCALAPPDATA%\三维动作捕捉标记点智能校准软件
启动失败时查看 logs\startup-error.txt。

Mac 与 Windows 之间搬移项目时，把项目 JSON 和它引用的原始 C3D
一起放到同一个文件夹。程序会在原路径失效后查找同文件夹中的源文件，
并校验 SHA256，防止加载同名但内容不同的试次。

四、此源码包与成品包的区别
当前提供的源码打包包需要在 Windows 上执行构建，尚不是 EXE 成品。
Mac 和 Windows 共用编辑器源码，但可执行程序需要分别构建。
只有 Windows 上的打包和 EXE 自检通过后，才得到成品 ZIP。
本包只含主编辑器；不含独立的 Heel 矫正脚本、旧矫正工具、
试次数据、项目记录、自动恢复记录或本机布局配置。
